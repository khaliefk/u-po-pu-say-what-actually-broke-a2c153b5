# Say What Actually Broke

One line of software error copy for the [make.fun bounty](https://make.fun/c/u-po-pu-say-what-actually-broke-a2c153b5): the brutal truth about a failure, funny on a single read, shippable in a real error dialog.

## The entry

> The server ran out of memory mid-save and dropped your work like a waiter dropping a tray. Nothing was saved, so try again, we have mopped the floor.

It names the real failure (server out of memory mid-save), says plainly what happened (nothing was saved) and what to do next (try again), and the waiter image is the part you repeat to a colleague.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (single line, 1–200 characters).
